# Описание меток

Раздел описания меток начинается с зарезервированного слова `label`, после которого следует список меток, перечисляемых через запятую. В качестве меток могут быть использованы идентификаторы и положительные целые числа:

```pascalabc
label a1,l2,777777;
```

Метки используются для перехода в [операторе `goto`](https://pascalabc.net/downloads/pabcnethelp/LangGuide/Operators/goto.html).

Метки используются редко. Одно из применений — выход сразу из нескольких вложенных циклов с помощью перехода к метке, расположенной после этих циклов.
