# Командный режим

Командный режим позволяет записывать программы без внешнего блока `begin`/`end`. Для этого в начале программы указывается префикс `##`:

```pascalabc
##
var a := ArrRandomInteger(10);
a.Println;
```

Этот режим предназначен для написания коротких программ из нескольких команд.

В командном режиме разрешено использовать одну секцию `uses` и описывать процедуры и функции. Например:

```pascalabc
##
uses GraphWPF;
procedure Draw(x, y: real) := Circle(x, y, 5);
Draw(100, 100);
```

## Ограничения

В отличие от [обычной структуры программы](program-structure.md), несколько секций `uses` в командном режиме не допускаются. Имена модулей и пространств имён следует перечислять через запятую в одной секции.
