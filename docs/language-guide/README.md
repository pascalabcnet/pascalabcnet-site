# Исходники официального руководства PascalABC.NET

Формат текстов: **Markdown (`.md`), кодировка UTF-8**. Кодировка закреплена в `.editorconfig` этого каталога. Здесь готовятся единые тексты для будущего веб-раздела Astro и локальной справки; публикация на сайте пока не подключена.

Старые HTML-файлы в `D:\PABC_GIT\PABCNetHelp\LangGuide` и `D:\PABC_GIT\PABCNetHelp\Common` остаются исходным материалом в Windows-1251. Новые тексты редактируются только в Markdown.

## Редакторские правила

- Это полное официальное описание языка, включая редко используемые и устаревшие возможности, а не учебник.
- Корректные исходные тексты сохраняются; изменения вносятся точечно.
- Основная структура программы включает `begin`/`end`. Командный режим `##` описывается отдельно.
- Глобальные переменные, метки и указатели не объявляются устаревшими только из-за редкого использования.
- Формы для совместимости оформляются отдельным выделенным блоком с заголовком **«Совместимость»**. В Markdown используется обычный блок цитирования с вложенным заголовком и примерами, без HTML-разметки и специальных расширений.
- Код PascalABC.NET помещается в блоки с меткой `pascalabc`.
- Ссылки на уже перенесённые страницы ведут на соседние `.md`; ссылки на ещё не перенесённые темы временно ведут в опубликованный HTML-справочник.
- Генерируемый раздел `PABCSystemUnit` пока не переносится и не редактируется.
