Небольшие программы, с которых удобно начать знакомство с PascalABC.NET.


## Первая программа

`Println` выводит значение и переводит курсор на новую строку.

```pascalabc
begin
  Println('Привет, PascalABC.NET!');
end.
```

## Ввод нескольких переменных. Вывод с помощью интерполированной строки

Можно ввести несколько значений и вывести результат с помощью интерполированной строки

```pascalabc
begin
  var (a,b) := ReadReal2('Введите a и b:');
  Println($'{a} + {b} = {a + b}');
end.
```


Если ввести:

```text
3 7
```

**Результат:**

```text
3 + 7 = 10
```

## Тип переменной и инициализация

Переменные можно объявлять с явным указанием типа или с автовыводом типа при инициализации:

```pascalabc
begin
  var a := 2.5;
  var b := 3.7;
  var s: real := 0;

  s += a;
  s += b;

  Println(s);
end.
```

**Результат:**

```text
6.2
```

## Целочисленное деление

Операции `div` и `mod` позволяют получить целую часть частного и остаток от деления.

```pascalabc
begin
  var a := 17;
  var b := 5;

  Println(a div b);
  Println(a mod b);
end.
```

**Результат:**

```text
3
2
```

## Стандартные функции и процедуры

Используем функцию `Min` для поиска минимального значения и процедуру `Swap` для обмена значений переменных.

```pascalabc
begin
  var a := 7;
  var b := 3;
  var c := 5;

  Println(Min(a, b, c));

  Swap(a, b);
  Println(a, b);
end.
```

**Результат:**

```text
3
3 7
```

## Возведение в степень

Операция `**` позволяет возводить число в заданную степень.

```pascalabc
begin
  var x := 3;

  Println(x ** 2);
  Println(x ** 3);
end.
```

**Результат:**

```text
9
27
```

## Максимальное значение `integer`

Свойство `integer.MaxValue` содержит максимальное значение типа `integer`.

```pascalabc
begin
  Println(integer.MaxValue);
end.
````

Результат:

```text
2147483647
```

## Длинные целые `BigInteger`

Тип `BigInteger` позволяет работать с целыми числами практически неограниченного размера. Суффикс `bi` задаёт литерал типа `BigInteger`.

```pascalabc
begin
  var n := 10_000_000_000bi;

  Println(n * n);
end.
```

Результат:

```text
100000000000000000000
```

## Вещественное деление на ноль

Вещественное деление на ноль не вызывает исключения: результатом может быть бесконечность или `NaN`.

```pascalabc
begin
  var z := 0.0;

  Println(1 / z);
  Println(0 / z);
end.
```
