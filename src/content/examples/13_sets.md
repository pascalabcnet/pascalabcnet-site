Множество `set of T` хранит только различные элементы и удобно для проверки принадлежности, удаления повторов и выполнения операций пересечения, объединения, разности множеств, проверки вложения и равенства множеств.

## Создание множества

Функция `SetOf` создаёт множество из перечисленных элементов. Повторы удаляются.
Множества выводятся внешней функцией `Print` в `{}`, а методом `Print` - через пробел.

```pascalabc
begin
  var s := SetOf(3,1,4,2,3);

  Println(s);
  s.Println;
end.
```

**Результат:**

```text
{3,1,4,2}
3 1 4 2
```


## Пустое множество

Пустое множество можно создать с помощью универсального инициализатора `[]`, явно указав его тип.

```pascalabc
begin
  var s: set of integer := [];

  Print(s);
end.
```

## Принадлежность множеству

Операция `in` проверяет, принадлежит ли элемент множеству.

```pascalabc
begin
  var s := SetOf(2,3,5,7);

  Println(5 in s);
  Println(6 in s);
end.
```

**Результат:**

```text
True
False
```

## Добавление и удаление элементов

Метод `Add` добавляет элемент в множество, а `Remove` - удаляет элемент из множества.
При добавлении имеющегося элемента и удалении несуществующего ничего не происходит.

```pascalabc
begin
  var s := SetOf(1,2,3);

  s.Add(7); 
  s.Add(1); 
  s.Remove(2);
  s.Remove(8);

  s.Print;
end.
````

**Результат:**

```text
1 3 7
```


## Перебор множества

Цикл `foreach` позволяет последовательно обработать все элементы множества.

```pascalabc
begin
  var s := SetOf(2,3,5,7);

  foreach var x in s do
    Print(x);
end.
```

## Количество элементов

Свойство `Count` возвращает количество элементов множества.

```pascalabc
begin
  var s := SetOf(2,3,5,7);

  Print(s.Count);
end.
```

**Результат:**

```text
4
```

## Объединение множеств

Операция `+` создаёт множество из элементов, входящих хотя бы в одно из двух множеств.

```pascalabc
begin
  var a := SetOf(1,2,3);
  var b := SetOf(3,4,5);

  Print(a + b);
end.
```

**Результат:**

```text
{1,2,3,4,5}
```


## Пересечение множеств

Операция `*` оставляет элементы, которые входят в оба множества.

```pascalabc
begin
  var a := SetOf(1,2,3,4);
  var b := SetOf(3,4,5,6);

  Print(a * b);
end.
```

**Результат:**

```text
{3,4}
```


## Разность множеств

Операция `-` оставляет элементы первого множества, которых нет во втором.

```pascalabc
begin
  var a := SetOf(1,2,3,4,5);
  var b := SetOf(2,4);

  Print(a - b);
end.
```

**Результат:**

```text
{1,3,5}
```



## Сравнение множеств

Два множества равны, если содержат одни и те же элементы независимо от порядка их перечисления.

```pascalabc
begin
  var a := SetOf(1,2,3);
  var b := SetOf(3,1,2);
  var c := SetOf(1,2,4);

  Println(a = b);
  Println(a = c);
end.
```

**Результат:**

```text
True
False
```

## Подмножество

Операции `<` и `<=` проверяют строгое и нестрогое включение одного множества в другое.

```pascalabc
begin
  var a := SetOf(1,2);
  var b := SetOf(1,2,3);
  var c := SetOf(1,2);

  Println(a < b);
  Println(a <= c);
  Println(b <= a);
end.
```

**Результат:**

```text
True
True
False
```

## Удаление повторов

Метод `ToSet` преобразует массив и список во множество, оставляя только различные элементы.

```pascalabc
begin
  var a := [3,1,2,3,2,4,1];

  var s := a.ToSet;

  Print(s);
end.
```
