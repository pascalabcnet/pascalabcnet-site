Лямбда-выражение — это безымянная функция, которую можно сохранить в переменной или передать другой функции как аргумент.

В PascalABC.NET удобно выделять три основных вида лямбда-выражений: **лямбда-преобразования**, **лямбда-условия** и **лямбда-проекции**.

## Лямбда-выражение как значение

Переменная функционального типа может хранить лямбда-выражение; тип такой переменной должен указываться явно.

```pascalabc
begin
  var f: real -> real := x -> x*x;
  var pred: (real,real) -> boolean := (x,y) -> x < y;

  f(5).Print;
  pred(3,2).Print;
end.
````

**Результат:**

```text
25 False
```

## Лямбда-преобразование

Лямбда-преобразование вычисляет новое значение по исходному элементу, сохраняя или изменяя его тип.

```pascalabc
begin
  var a := Arr(1..5);

  var squares := a.Select(x -> x * x);

  squares.Println;
end.
```

**Результат:**

```text
1 4 9 16 25
```

Лямбда-преобразование может возвращать значение другого типа.

```pascalabc
begin
  var a: array of integer := Arr(1..5);

  var strings: array of string := a.Select(x -> x.ToString).ToArray;

  strings.Println;
end.
```

**Результат:**

```text
1 2 3 4 5
```

## Лямбда-условие

Лямбда-условие возвращает логическое значение и используется для отбора элементов по заданному критерию.

```pascalabc
begin
  var a := Arr(1..10);

  var even := a.Where(x -> x mod 2 = 0);

  even.Println;
end.
```

**Результат:**

```text
2 4 6 8 10
```

## Лямбда-проекция

Лямбда-проекция извлекает часть составного объекта.

```pascalabc
begin
  var items := [
    ('apple',1.5),
    ('banana',1.2),
    ('cherry',0.9)
  ];

  var names := items.Select(x -> x.Item1);

  names.Println;
end.
```

**Результат:**

```text
apple banana cherry
```

## Лямбда как параметр функции

Лямбду можно передать как параметр функции. В данном примере лямбда-функция f применяется ко всем элементам массива, преобразуя его в новый массив.
Данная функция - обобщенная, может преобразовывать массив любого типа в массив другого типа.

```pascalabc
function Transform<T,T1>(a: array of T; f: T -> T1): array of T1;
begin
  Result := new T1[a.Length];

  for var i := 0 to a.Length - 1 do
    Result[i] := f(a[i]);
end;

begin
  var a := [1,2,3,4,5];

  Transform(a, x -> x*x).Println;
  Transform(a, x -> $'#{x}').Println;
  Transform(a, x -> x.IsEven).Println;
end.
````

**Результат:**

```text
1 4 9 16 25
#1 #2 #3 #4 #5
False True False True False
```


## Преобразование и условие в одной цепочке

Лямбда-условия и лямбда-преобразования можно последовательно применять к одной последовательности.

```pascalabc
begin
  var a := Arr(1..10);

  a.Where(x -> x mod 2 = 0)
   .Select(x -> x * x)
   .Println;
end.
```

**Результат:**

```text
4 16 36 64 100
```

## Генерация массива по индексу

`ArrGen` может создавать массив, вычисляя значение каждого элемента с помощью лямбда-преобразования.

```pascalabc
begin
  var a := ArrGen(10,i -> i*i,1);

  a.Println;
end.
```

**Результат:**

```text
1 4 9 16 25 36 49 64 81 100
```

## Генерация массива по предыдущему значению

`ArrGen` может вычислять каждый следующий элемент массива на основе предыдущего значения.

```pascalabc
begin
  var a := ArrGen(10,1,x -> x*2);

  a.Println;
end.
```

**Результат:**

```text
1 2 4 8 16 32 64 128 256 512
```
