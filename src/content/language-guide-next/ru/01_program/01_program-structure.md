Программа на языке PascalABC.NET содержит [ключевые слова и идентификаторы](/language-guide/identifiers/), а также может содержать [комментарии](/language-guide/comments/). Ключевые слова используются для выделения синтаксических конструкций и подсвечиваются жирным шрифтом в редакторе. Идентификаторы служат именами переменных, констант, типов, подпрограмм и других объектов программы и не могут совпадать с ключевыми словами.

## Общая структура программы

Программа имеет следующую общую структуру:

```pascalabc
раздел uses
раздел описаний
begin
  операторы
end.
```

Раздел `uses` и раздел описаний могут отсутствовать. Основной блок программы начинается словом `begin` и заканчивается словом `end`, после которого ставится точка.

## Раздел uses

[Раздел `uses`](/language-guide/uses/) подключает модули и пространства имён .NET. Он состоит из одной или нескольких подряд идущих секций `uses`. В каждой секции имена перечисляются через запятую:

```pascalabc
uses GraphABC, Timers, System.Text;
```

Можно также записать каждую секцию `uses` на отдельной строке:

```pascalabc
uses GraphABC;
uses Timers;
uses System.Text;
```

## Раздел описаний

Раздел описаний может включать:

- [описания переменных](/language-guide/variables/);
- [описания констант](/language-guide/constants/);
- [описания типов](/language-guide/type-declarations/);
- [описания меток](/language-guide/labels/);
- [описания процедур и функций](/language-guide/routines/).

Эти подразделы могут следовать друг за другом в произвольном порядке. 

## Блок основной программы

Блок основной программы `begin`/`end` содержит [операторы](/language-guide/statements/), отделяемые друг от друга точкой с запятой; в конце программы ставится точка. Среди операторов может быть [оператор описания переменной](/language-guide/variable-statement/), позволяющий объявлять переменные непосредственно внутри блока.

Например, следующая программа вводит два целых числа и выводит результат их деления:

```pascalabc
begin
  var (a,b) := ReadInteger2;
  var x: real := a/b;
  Println(x);
end.
```

Переменные `a` и `b` объявлены и инициализированы вызовом функции `ReadInteger2` - их тип выводится автоматически по типу возвращаемого значения функции. Тип переменной `x` указывается явно. Запись `(a,b) := ReadInteger2` использует [распаковку](/language-guide/deconstruction/) результата функции в две переменные.

Пример программы с подключением графического модуля:

```pascalabc
uses GraphABC;

begin
  var x := 100;
  var y := 100;
  var r := 50;
  Circle(x,y,r);
end.
```

## Глобальные переменные

Переменные, объявленные до `begin` основной программы, называются глобальными. Их используют, в частности, для хранения данных, общих для нескольких процедур и функций.

С появлением внутриблочных объявлений глобальные переменные используются редко, но не являются устаревшими. При прочих равных условиях предпочтительны именно внутриблочные объявления. 
Однако если переменная должна быть доступна нескольким процедурам и функциям, её можно объявить глобально.

В следующем примере переменная `x` доступна как в основном блоке программы, так и в процедуре `Draw`:

```pascalabc
uses GraphWPF;

var x: integer := 100;

procedure Draw := Circle(x,300,5);

begin
  loop 10 do
  begin
    Draw;
    x += 10;
    Sleep(500);
  end;
end.
```

## Короткая форма программы

Программа может быть записана в короткой форме без внешнего блока `begin`/`end` с указнием в начале префикса `##`:

```pascalabc
##
var a := ArrRandomInteger(10);
a.Println;
```

Такой режим называется также командным способом записи программы, т.к. в простейшем случае содержит просто надор команд (операторов программы), выполняемых одна за другой.

Подробное описание этой формы и её ограничений приведено на странице [Короткая форма программы](/language-guide/short-program/).

> ## Совместимость
>
> Для совместимости поддерживается необязательный **заголовок программы**, который указывается перед разделом `uses` и разделом описаний:
>
> ```text
> program имя программы;
> ```
>
> Заголовок задаёт имя программы. Например:
>
> ```pascalabc
> program MyHelloProgram;
> begin
>   Print('Hello PascalABC.NET!');    
> end.
> ```
