Переменные могут быть описаны в **разделе описаний**, а также непосредственно внутри любого [блока](/language-guide/compound-statement/) `begin`/`end`.

Раздел описания переменных располагается перед блоком `begin/end` программы или после заголовка подпрограммы перед её блоком `begin/end`. Он начинается с ключевого слова `var`, после которого следуют одна или несколько строк описания:

```pascalabc
var
  список имен: тип;
  имя: тип := выражение;
  имя := выражение;
```

Имена в списке перечисляются через запятую. В записи `имя := выражение` тип определяется по типу выражения справа; в остальных вариантах он указан явно. Например:

```pascalabc
var
  a,b,c: integer;
  d: real := 3.7;
  s := 'PascalABC.NET forever';
  lst := new List<integer>;
  p1 := 1;
begin
  // Операторы
end.
```

Переменные также могут быть описаны непосредственно внутри блока `begin/end` - такие описания называют **внутриблочными** и образуют [оператор описания переменной](/language-guide/variable-statement/). 

```pascalabc
begin
  var a := ReadInteger;
  var a2 := a * a;
end.
```

В PascalABC.NET **внутриблочные описания представляют собой основную форму описания переменных**. ООни позволяют описывать переменную непосредственно перед первым использованием, сразу инициализировать её и ограничивать область видимости тем блоком, где она действительно нужна.

Описание большого числа переменных перед begin, если они используются в разных частях программы, снижает локальность кода: объявление переменной оказывается удалено от места её использования, а зависимости между переменными становятся менее очевидными.

Кроме того, переменные-параметры цикла могут описываться в заголовке операторов [`for`](/language-guide/for/) и [`foreach`](/language-guide/foreach/):

```pascalabc
for var i:=1 to 10 do
  Print(i);
foreach var x in [2,5,6] do
  Print(x);  
```

Это также соответствует принципу локальности: переменная объявляется непосредственно в месте использования, а её область видимости ограничена данным циклом.

**Глобальные переменные** — это переменные, описанные перед основным блоком `begin/end` программы. Они гарантированно инициализируются нулевыми значениями. Все остальные переменные являются **локальными** — их надо инициализировать явно, неявная инициализация нулями для них не гарантируется.

## Совмещение описания переменных и кортежного присваивания

[Кортежное присваивание](/language-guide/tuples/) (распаковку кортежа в переменные) можно совмещать с описанием переменных:

```pascalabc
var t := (1,2);
(var a, var b) := (1,2);
```

или

```pascalabc
var (a,b) := (1,2);
```

Распаковка кортежа в переменные часто используется если функция возвращает кортеж:

```pascalabc
function SP(a,b: real) := (a*b, 2*(a+b));
 ...
var (S,P) := SP(2,3);
```

> ## Совместимость с Delphi
>
> Для совместимости с Delphi при описании переменной с инициализатором и типом поддерживается также запись с `=`:
>
> ```pascalabc
> var 
>   имя: тип = выражение;
> ```
>
> В новом коде рекомендуется использовать `:=`.
