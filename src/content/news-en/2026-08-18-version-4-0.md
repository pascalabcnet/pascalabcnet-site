PascalABC.NET 4.0 has been released.

**PascalABC.NET 4.0** is a new generation of the PascalABC.NET programming system.

Its main additions are **multitarget** support for .NET Framework 4.7.2 and .NET 10, the official PascalABC.NET extension for Visual Studio Code with IntelliSense, and the new **ML PascalABC.NET** library for data analysis and machine learning.
