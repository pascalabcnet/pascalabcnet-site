## Что такое PascalABC.NET

PascalABC.NET — современный статически типизированный язык программирования общего назначения и система программирования на платформе .NET.

Он развивает традиции языка Pascal: сохраняет его понятный синтаксис и основные принципы, дополняя их современными языковыми конструкциями и возможностями платформы .NET. Сегодня PascalABC.NET развивается как самостоятельный язык, заметно отличающийся и от классического Паскаля, и от Delphi.

На PascalABC.NET можно написать первую программу в несколько строк, изучать алгоритмы и структуры данных, осваивать объектно-ориентированное и функциональное программирование, решать олимпиадные задачи, использовать библиотеки .NET, выполнять научные расчёты, анализировать данные и строить модели машинного обучения.

Такой диапазон возможностей отражает одну из ключевых идей PascalABC.NET: **сделать современное программирование доступным для изучения и одновременно создать полноценный универсальный язык**.

## Идея PascalABC.NET

Между первыми шагами в программировании и созданием сложных программ часто возникает разрыв: по мере роста задач вместе с новыми понятиями быстро растёт и техническая сложность.

PascalABC.NET позволяет пройти этот путь в одной языковой среде: от первых программ и классических алгоритмов до современных абстракций, библиотек .NET и сложных программных проектов.

Язык остаётся статически типизированным и компилируемым: компилятор обнаруживает многие ошибки ещё до запуска программы, а скомпилированный код обеспечивает высокую эффективность выполнения.

В основе PascalABC.NET лежит **баланс простоты, раннего обнаружения ошибок, выразительности и эффективности**.

PascalABC.NET развивается вместе с современным программированием. При развитии языка и системы учитываются идеи современных языков, компиляторов и библиотек, опыт собственной инженерной разработки и многолетняя практика использования — в том числе в обучении школьников и студентов.

Новые возможности не переносятся механически. Каждая из них рассматривается с точки зрения **целостного дизайна языка**: насколько естественно она сочетается с уже существующими конструкциями, делает программы яснее и выразительнее, сохраняет предсказуемость поведения и не создаёт неоправданной сложности.

Именно баланс этих требований определяет развитие PascalABC.NET.

## Принципы языка

### От алгоритмов к современным абстракциям

Одна из принципиальных особенностей PascalABC.NET — возможность естественно переходить от классического алгоритмического программирования к современным способам обработки данных, не теряя понимания того, что происходит внутри.

Возьмём простую задачу: дан массив слов, нужно получить длины этих слов. В алгоритмической форме это обычный цикл

```pascalabc
var a := ['холодный','белый','плохой','злой','спелый'];
foreach var word in a do
  Print(word.Length);
```

Ту же задачу можно решить, используя метод преобразования `Select` и лямбда-выражения:

```pascalabc
a.Select(word -> word.Length).Print;
```

Это одна и та же программная идея, выраженная на разных уровнях абстракции. Тот, кто понимает работу цикла, может видеть в `Select` не отдельный механизм, а более компактную форму знакомого преобразования последовательности.

Операции более высокого уровня естественно объединяются в цепочки. Например, минимальную длину слова можно получить так:

```pascalabc
a.Select(word -> word.Length).Min
```

При этом не требуется заново строить алгоритм обхода массива: программа непосредственно выражает последовательность преобразований данных.

Связь работает и в обратную сторону: библиотечную операцию можно рассматривать как абстракцию над определённым алгоритмом и при необходимости разбирать её реализацию. Это позволяет постепенно переходить от явных алгоритмов к более декларативному стилю программирования, не противопоставляя эти подходы друг другу.

### Статическая типизация и раннее обнаружение ошибок

PascalABC.NET — статически типизированный компилируемый язык. Ещё до запуска программы компилятор проверяет синтаксис, совместимость типов, области видимости, корректность вызовов и другие семантические условия.

Например, в коде:

```pascalabc
var n := 10;
n := 'abc';
```

переменная `n` имеет тип `integer`, выведенный при её объявлении, поэтому присвоить ей строку нельзя. Ошибка обнаруживается компилятором до запуска программы.

Для обучения это особенно важно: программист с самого начала видит, что у каждого значения есть тип, какие операции над этим типом допустимы и почему конкретная строка программы ошибочна.

При этом PascalABC.NET не требует указывать тип там, где он однозначно определяется из контекста. Явное описание типов и автовывод типов существуют в языке вместе, сочетая строгость статической типизации с компактностью записи.

Освоенные в PascalABC.NET понятия хорошо переносятся на другие современные языки. Типы, области видимости, функции, классы, интерфейсы, обобщения и лямбда-выражения непосредственно узнаются в C#, Java и C++. Переход к динамически типизированным языкам также становится осмысленнее: уже сформировано представление о типах и о том, какие проверки в статически типизированном языке выполняет компилятор.

### Явное указание типов и автовывод

PascalABC.NET не навязывает единственный способ записи программы.

Тип переменной можно указать явно:

```pascalabc
var n: integer := 10;
```

или позволить компилятору вывести его по правой части:

```pascalabc
var n := 10;
```

В обоих случаях создаётся статически типизированная переменная. Полная запись полезна, когда тип существенен для понимания программы или является предметом изучения; автовывод — когда тип очевиден и его повторение только перегружает код.

То же относится к сложным выражениям. Цепочку операций

```pascalabc
var sum := a.Where(x -> x in 2..5).Sum;
```

можно разбить на именованные шаги:

```pascalabc
var filtered := a.Where(x -> x in 2..5);
var sum := filtered.Sum;
```

PascalABC.NET не стремится к краткости любой ценой. Форма записи выбирается так, чтобы программа оставалась достаточно компактной и при этом хорошо читалась.

### Разные парадигмы программирования

На PascalABC.NET можно писать программы в [процедурном, объектном, объектно-ориентированном и функциональном стилях](https://pascalabcnet.github.io/mydoc_progr_styles.html), а также сочетать эти подходы.

Язык поддерживает классы, наследование, интерфейсы, полиморфизм, обобщённые классы и подпрограммы, перегрузку операций, исключения, методы расширения, лямбда-выражения и другие современные средства.

Это позволяет использовать один язык для задач разного уровня: от явных алгоритмов с циклами и условиями до объектных моделей, обобщённого программирования и функциональной обработки последовательностей.

### Короткий код — не самоцель

В PascalABC.NET многое сделано для компактной записи программ: автовывод типов, диапазоны, срезы, кортежи, операции `+=` и `*=`, лямбда-выражения, цепочки методов.

Но краткость не является целью сама по себе. Короткая запись полезна, если она делает программу понятнее или точнее выражает операцию. Если промежуточные шаги важны для понимания, их лучше сделать явными.

Поэтому PascalABC.NET стремится не к минимальному количеству символов, а к **разумной компактности при сохранении структуры и читаемости кода**.

## Происхождение и развитие языка

История PascalABC.NET началась в 2002 году с учебной системы Pascal ABC. **В 2007 году** началась разработка нового языка и компилятора для платформы .NET, и с этого времени PascalABC.NET развивается как самостоятельный язык программирования.

Его синтаксическая основа связана с Pascal и Object Pascal, существенное влияние на архитектуру языка оказал C#, а в дальнейшем в PascalABC.NET использовались и переосмысливались удачные идеи Python, Kotlin, Java, Haskell и других современных языков.

Развитие PascalABC.NET не сводится к переносу отдельных конструкций из других языков. Каждая новая возможность рассматривается с точки зрения **целостного дизайна языка**: насколько естественно она сочетается с существующими средствами, делает программы понятнее и выразительнее, сохраняет предсказуемость поведения и не создаёт неоправданной сложности.

Некоторые решения появились в PascalABC.NET значительно раньше, чем в других языках паскалевской традиции. Например, объявление переменной непосредственно в заголовке цикла

```pascalabc
for var i := 1 to 10 do
```

используется в PascalABC.NET с 2007 года — более чем за десять лет до появления аналогичной конструкции в Delphi.

Внутриблочные описания переменных, автовывод типов, расширенные циклы, диапазоны, кортежные операции, методы расширения, лямбда-выражения и последовательности сегодня определяют собственный стиль программирования на PascalABC.NET.

Поэтому PascalABC.NET правильнее рассматривать не как «современную реализацию старого Паскаля», а как **самостоятельный современный язык с Pascal-подобным синтаксисом и собственной линией развития**.

## Применение PascalABC.NET

### Обучение, ЕГЭ и олимпиады

PascalABC.NET продолжает использоваться в школьном обучении программированию, при подготовке к ЕГЭ по информатике и в олимпиадной практике.

Язык поддерживается рядом систем проведения соревнований и автоматической проверки решений, включая Яндекс Контест, Codeforces и ACMP.ru. Выразительные средства языка и развитые библиотеки позволяют писать компактные решения и сосредоточиться на алгоритме задачи.

Для школьного обучения программированию вокруг PascalABC.NET сформирована собственная инфраструктура:

1. встроенный электронный задачник [Programming Taskbook](http://www.ptaskbook.com/);
2. учебные исполнители **Робот** и **Чертёжник**;
3. механизм автоматически проверяемых заданий;
4. **LightPT** — легковесная невидимая система автоматической проверки программ;
5. графические учебные модули.

### В высшем образовании

PascalABC.NET используется и в университетском преподавании — в том числе как первый язык программирования на профильных ИТ-направлениях.

Например, на направлении «Фундаментальная информатика и информационные технологии» мехмата Южного федерального университета с PascalABC.NET ежегодно начинают изучение программирования около ста студентов. Язык используется также при подготовке будущих учителей информатики.

Такой опыт показывает, что PascalABC.NET подходит не только для знакомства с алгоритмами, но и для систематического университетского курса программирования — с переходом от базовых конструкций к типам, коллекциям, объектно-ориентированному и функциональному программированию, библиотекам и более сложным программным абстракциям.

### В научных вычислениях и анализе данных

Как язык общего назначения на платформе .NET, PascalABC.NET предоставляет доступ к библиотекам .NET и может использоваться для обработки данных, математических вычислений, моделирования и вычислительных экспериментов.

Для анализа данных и машинного обучения развивается библиотека [ML PascalABC.NET](https://pascalabcnet.github.io/ai/) без внешних зависимостей, включающая средства работы с табличными данными, линейной алгеброй, статистикой и алгоритмами машинного обучения.

Компилятор PascalABC.NET поддерживает **.NET 10**, поэтому из языка доступны библиотеки и API современной платформы .NET.

## Среды разработки и компиляторы

PascalABC.NET — это не только язык, но и система программирования.

Собственная IDE PascalABC.NET ориентирована на простой старт и одновременно предоставляет средства повседневной разработки: автодополнение, подсказки по коду, автоматическое форматирование, диагностику ошибок, примеры программ, средства автоматической проверки решений и модульного тестирования.

[Расширение PascalABC.NET для Visual Studio Code](/vscode/) предоставляет IntelliSense, диагностику ошибок, компиляцию и запуск программ и позволяет работать с PascalABC.NET в современной кроссплатформенной среде разработки.

Для PascalABC.NET доступны два компилятора:

- компилятор для .NET Framework 4.7.2, работающий в Windows и Linux через Mono;
- современный компилятор PascalABC.NET для .NET 10, поддерживающий Windows, Linux и macOS.

Таким образом, PascalABC.NET сочетает простую специализированную IDE для быстрого старта с возможностью использовать Visual Studio Code и современную кроссплатформенную платформу .NET.
