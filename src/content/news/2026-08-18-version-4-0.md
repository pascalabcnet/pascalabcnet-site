Вышла версия PascalABC.NET 4.0.

**PascalABC.NET 4.0** — новое поколение системы программирования PascalABC.NET.

Главные изменения версии 4.0 — **multitarget**-поддержка .NET Framework 4.7.2 и .NET 10, 
официальное расширение PascalABC.NET для Visual Studio Code с IntelliSense и 
новая библиотека **ML PascalABC.NET** для анализа данных и машинного обучения.

[Что нового в 4.0 →](https://pascalabc.net/whats-new/pascalabcnet-4.0)
